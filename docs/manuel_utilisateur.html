Introduction

CommonLedger est une application de bureau Windows qui automatise la comptabilité annuelle d'une petite association à partir des relevés bancaires PDF La Banque Postale (CCP). Elle génère automatiquement un compte de résultat complet avec graphiques, prêt à présenter en assemblée générale.

Accessibilité totale : CommonLedger a été conçu dès le départ pour être 100% utilisable sans souris, avec une compatibilité complète NVDA et JAWS via l'API UIA de Windows.

Ce que fait CommonLedger

  • Extrait automatiquement toutes les transactions depuis vos relevés PDF
  • Catégorise les dépenses et recettes par règles (cotisations, loyers, etc.)
  • Gère les virements complexes (HelloAsso, éclatement multi-catégories)
  • Génère un rapport Word/PDF professionnel avec graphiques
  • Produit des exports CSV pour audit
  • Permet une comptabilité analytique par projet (concerts, tournées…)

Ce que CommonLedger ne fait pas

  • Il ne remplace pas un expert-comptable pour les grandes associations
  • Il ne gère pas la comptabilité en partie double (plan comptable général)
  • Il ne se connecte pas directement à la banque (import manuel des PDFs)

Installation

Prérequis

  • Windows 10 ou 11 (64 bits)
  • Python 3.11 ou supérieur — python.org/downloads
  • Microsoft Word (optionnel, pour la conversion PDF)

Installation depuis les sources

  1. Télécharger le projet depuis https://github.com/aminekhettat/commonledger
  2. Ouvrir une invite de commande dans le dossier du projet
  3. Créer un environnement virtuel : python -m venv venv
  4. Activer l'environnement : venv\Scripts\activate
  5. Installer les dépendances : pip install -r requirements.txt
  6. Copier le fichier de configuration : copy config\association.example.json config\association.json
  7. Lancer l'application : python main.py
Première utilisation : À l'ouverture, allez directement dans l'onglet Paramètres (Alt+5) pour renseigner les informations de votre association avant tout import.

Première utilisation — Flux de travail recommandé

  1. Paramètres (Alt+5) — Renseigner nom, SIRET, Waldec, IBAN, logo
  2. Import (Alt+1) — Sélectionner le dossier des relevés PDF, saisir le solde au 1er janvier, cliquer sur Importer
  3. Catégorisation (Alt+2) — Vérifier les transactions non reconnues et les catégoriser manuellement
  4. Rapport (Alt+3) — Cliquer sur "Calculer" pour voir le graphique et l'aperçu, puis "Générer le rapport"

1. Import des relevés NVDA ✓

L'onglet Import (accessible par Alt+1) permet d'extraire les transactions depuis les fichiers PDF de relevés La Banque Postale.

Procédure d'import

  1. Sélectionner l'année de l'exercice avec les flèches ou en tapant directement (ex: 2024)
  2. Saisir le solde bancaire au 1er janvier de l'exercice (trouvable sur le dernier relevé de décembre de l'année précédente)
  3. Indiquer le dossier contenant les PDFs : taper le chemin ou utiliser le bouton Parcourir (Alt+P)
  4. Cliquer sur Importer les relevés (Alt+I)
  5. Patienter — le journal affiche la progression fichier par fichier
  6. À la fin, un résumé indique le nombre de transactions importées et celles à catégoriser manuellement

Format des PDFs acceptés

BanqueFormat de nomAnnées supportées
La Banque Postale (CCP)releve_6804150W020_2024-01-31.pdf2013 – 2026
La Banque Postale (CCP)releve_CCP6804150W020_20240131.pdf2013 – 2022
Important : Placez tous les relevés d'une même année dans un seul dossier. Ne mélangez pas les années. Un dossier par exercice comptable.

Ce qui est extrait automatiquement

  • Date, libellé et montant de chaque transaction
  • Soldes de début et fin de période (pour vérification de cohérence)
  • Période couverte par chaque relevé (depuis le texte du PDF, jamais depuis le nom de fichier)

Catégorisation automatique

Après import, CommonLedger applique automatiquement des règles par mots-clés pour catégoriser la majorité des transactions. En général, 85-95% des transactions sont reconnues automatiquement.

2. Catégorisation NVDA ✓

L'onglet Catégorisation (Alt+2) affiche toutes les transactions dans un tableau. Les transactions non catégorisées ont un fond jaune, les catégorisées ont un fond vert, les éclatées (splits) ont un fond bleu clair.

Catégoriser une transaction

  1. Naviguer jusqu'à la ligne souhaitée avec les flèches
  2. Appuyer sur Entrée — le dialogue de catégorisation s'ouvre
  3. Choisir la catégorie dans la liste déroulante
  4. Optionnel : choisir un projet analytique
  5. Optionnel : saisir un mémo libre
  6. Confirmer avec Alt+V (Valider) ou Entrée

Éclater une transaction (split)

Utilisez l'éclatement quand un seul virement correspond à plusieurs postes comptables. Exemple typique : un virement HelloAsso contenant à la fois des cotisations et des dons.

  1. Ouvrir la catégorisation d'une transaction
  2. Cliquer sur "✂ Éclater cette transaction" (Alt+E)
  3. Pour chaque partie : choisir une catégorie, saisir le montant, optionnellement un projet
  4. Vérifier que le "Restant à ventiler" affiche 0,00 €
  5. Valider le split
Astuce NVDA : Dans le dialogue de split, le label "Restant à ventiler" est mis à jour en temps réel. Utilisez F5 dans NVDA pour forcer la lecture du texte dynamique.

Colonne Projet

La colonne Projet du tableau affiche le projet associé à chaque transaction. Pour affecter un projet, ouvrir la catégorisation et choisir dans la liste "Projet (optionnel)". Voir la section Projets analytiques.

3. Rapport NVDA ✓

L'onglet Rapport (Alt+3) permet de visualiser les résultats et d'exporter le rapport dans différents formats.

Interface du panneau Rapport

Le panneau est divisé en deux parties séparées par un séparateur glissant :

  • Gauche : sélecteur de graphique + canvas interactif
  • Droite : aperçu textuel du compte de résultat + options export

Graphique interactif

Quatre types de graphiques sont disponibles dans la liste déroulante :

TypeDescription
Camembert — RecettesRépartition des recettes par catégorie (donut)
Camembert — DépensesRépartition des dépenses par catégorie (donut)
Histogramme mensuelRecettes vs dépenses mois par mois
Courbe de trésorerieÉvolution du solde bancaire sur la période

Filtres disponibles

  • Période : Annuel (1er janvier → 31 décembre) ou Personnalisé
  • Projet : Tous les projets ou un projet spécifique

Générer le rapport

  1. Sélectionner la période et le projet souhaités
  2. Cliquer sur "🔄 Calculer" — l'aperçu et le graphique se mettent à jour
  3. Choisir le type de graphique dans la liste déroulante
  4. Cliquer sur "📄 Générer le rapport complet" (Alt+G)
  5. Choisir l'emplacement de sauvegarde du fichier .docx
  6. Patienter — Word puis PDF sont générés automatiquement

Formats d'export

FormatContenuUsage
Word (.docx)Rapport complet avec graphiques et tableauxPrésentation AG, impression
PDFConversion du WordArchivage, envoi par email

Structure du rapport Word généré

  1. Page de garde (logo, résumé financier)
  2. Sommaire automatique
  3. Informations de l'association
  4. Compte de résultat (recettes et dépenses par catégorie)
  5. Visualisation graphique (camemberts + histogramme)
  6. Évolution de la trésorerie
  7. Détail des opérations par catégorie
  8. Comptabilité analytique par projet (si projets définis)
  9. Signature du trésorier

4. Projets analytiques NVDA ✓

L'onglet Projets (Alt+4) permet de créer des projets pour regrouper les recettes et dépenses d'un événement spécifique : concert, tournée, atelier, forum des associations, etc.

Créer un projet

  1. Cliquer sur "➕ Nouveau projet" (Alt+N)
  2. Saisir le nom du projet (obligatoire)
  3. Optionnel : description, date de début, budget prévisionnel
  4. Valider — le projet apparaît dans la liste

Affecter des transactions à un projet

Dans l'onglet Catégorisation (Alt+2), ouvrir une transaction, choisir le projet dans la liste "Projet (optionnel)". Pour un split, chaque partie peut avoir son propre projet.

Consulter le bilan d'un projet

Dans l'onglet Rapport (Alt+3), sélectionner le projet dans le filtre "Projet". Le graphique et l'aperçu textuel ne montreront que les transactions de ce projet. Le rapport généré inclura une section "Comptabilité analytique par projet".

Sous-onglet Catégories

Vous pouvez ajouter, modifier ou supprimer des catégories de recettes et de dépenses. Les catégories existantes sont pré-configurées pour une association culturelle type.

Attention : Supprimer une catégorie utilisée par des transactions existantes rendra ces transactions "non catégorisées". Préférez renommer plutôt que supprimer.

Accessibilité NVDA et JAWS

CommonLedger a été développé par et pour des personnes déficientes visuelles. Voici les spécificités à connaître pour une utilisation optimale.

Configuration recommandée avec NVDA

  • Mode de navigation : désactivé (Ctrl+NVDA+Espace) — l'application utilise le mode Application
  • Verbosité des tableaux : Activer l'annonce des en-têtes (NVDA → Préférences → Mise en forme des documents)
  • Délai de lecture des barres de progression : régler à "parler" dans les paramètres NVDA

Lecture du tableau de catégorisation

NVDA annonce chaque cellule avec son en-tête de colonne : par exemple "Date, 03/01/2024, Libellé, PRELEVEMENT DE PayPal…, Montant, -16,00 €". Utilisez Ctrl+Alt+Flèches pour naviguer cellule par cellule.

Graphiques

Les graphiques matplotlib ne sont pas directement lisibles par les lecteurs d'écran. Un tableau alternatif textuel est affiché sous chaque graphique dans les rapports Word/PDF. Dans l'interface, le texte de l'aperçu (panneau droit de l'onglet Rapport) donne les mêmes informations en format texte.

JAWS — différences avec NVDA

  • JAWS active automatiquement le "mode formulaire" sur les champs de saisie
  • Pour les tableaux, utiliser F8 dans JAWS pour lister les colonnes
  • Les dialogues modaux sont correctement annoncés par les deux lecteurs
Raccourci utile avec NVDA : Dans le tableau des transactions, appuyer sur NVDA+Ctrl+C pour copier le contenu de la cellule active.

Questions fréquentes

Le parseur ne trouve pas mes PDFs, que faire ?

Vérifiez que l'IBAN et le numéro de compte dans les Paramètres correspondent exactement à ceux figurant sur les relevés. CommonLedger vérifie l'appartenance du fichier avant d'extraire les données.

J'ai un écart entre le solde calculé et le solde réel

Cela indique des transactions non catégorisées ou un solde initial incorrect. Vérifiez que toutes les transactions sont catégorisées (onglet Catégorisation, filtre "Non catégorisées") et que le solde au 1er janvier est correct.

Le don de Nawel Kerdali n'apparaît pas dans le rapport 2024

Ce don de 500€ (SELARL du Docteur Nawel Kerdali) a été reçu en novembre 2023, pas en 2024. Il apparaîtra dans le rapport 2023.

Comment gérer un virement HelloAsso avec cotisations et dons mélangés ?

Ouvrir la transaction HelloAsso → Entrée → cliquer sur "✂ Éclater cette transaction" → Ajouter autant de lignes que nécessaire (cotisations pour X€, dons pour Y€) → Vérifier que le restant affiche 0,00€ → Valider.

Le rapport PDF ne se génère pas

La conversion PDF nécessite Microsoft Word ou LibreOffice. Vérifiez qu'un de ces logiciels est installé. Le fichier Word (.docx) est toujours généré, indépendamment de la conversion PDF.

Puis-je utiliser CommonLedger avec une autre banque ?

La version actuelle supporte uniquement La Banque Postale (CCP). Le projet est open source — des contributions pour d'autres banques (Crédit Agricole, BNP, Société Générale) sont les bienvenues sur GitHub.
